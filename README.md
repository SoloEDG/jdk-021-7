# 午市厨房 · Lunch Rush

需要 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

类型检查、生产构建与仿真测试：

```sh
npm run typecheck
npm run build
npm run sim   # 14 项无头仿真：移动避让、归属唯一、断点拦截、完整出账链路
```

Docker 启动：

```sh
docker compose up --build
```

打开 http://localhost:18221 。

## 玩法与机制

在原有接单、火候、失温、收益规则之上，新增一层 **格子布局 + 双厨师搬运** 系统：

- **可编辑格子布局（10×7）**：开餐前可自由砌墙、拆墙、拖动备料台 / 灶台 / 传菜口 / 食材库；营业中只能挪设备。
- **走路占用营业时间**：所有操作都变成「派任务 → 厨师走过去 → 到站执行」，每 0.1 秒走一格。
- **窄过道单人通行**：同一格同一时刻只容一人；两位厨师迎面相遇**不会互相穿过**，也**不会永久等待**——按策略自动后退让行或重新规划绕行，并有 15 拍强制兜底。
- **火候不等人**：厨师赶路期间灶上的菜持续加热，到点不起锅就会焦糊。
- **食品唯一归属，绝不瞬移**：备料 / 成品有「在台面」与「某厨师手持」两种状态，同一份不能重复派单；取消在途任务或挪动设备时，手持食品放回原台面。
- **营业中挪设备的守卫**：灶上有菜直接拒绝；有正在前往该设备的任务时先撤回整条任务链，再移动，路径按新位置重新规划。
- **出口连通性校验**：传菜口与所有设备、两个厨师站位必须在同一连通域；有断点时拒绝开餐，并在布局台用 ✕ 标红具体格子。
- **三种手动策略**：每位厨师可在「自动避让 / 绕远路 / 等通道让行」之间切换，界面实时显示规划路径、等待原因与手持食品。
- **拥堵基准**：布局 A（横墙单门）内置「近路 vs 绕行」对照，可一键验证迎头拥堵反而比绕远路更慢。

## 目录

```
src/features/flow/
  lib/grid.ts        # 网格、BFS 寻路、预设布局、连通性校验
  lib/movement.ts    # 协作移动：占位、禁互换、后退、绕行、不死锁兜底
  model/tasks.ts     # 搬运任务链、唯一归属、改派/取消、到站业务执行
  model/editor.ts    # 布局编辑与营业中挪设备守卫
  model/engine.ts    # 每个时间片驱动 + 完工让位
  model/benchmark.ts # 近路/绕行拥堵基准（只读模拟）
  ui/                # 布局台、厨师面板、任务队列、基准卡片
scripts/             # 无头仿真测试（不依赖浏览器）
```
